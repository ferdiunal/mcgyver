05 · Private by design

Your files stay. Right where they are.

Converting a file doesn't mean uploading it. McGyver does the work on your own computer.

Local conversionholiday.jpg → holiday.webp
Your computer
holiday.jpg

on this device

Sharing is different. When you choose Share, WhatsApp or Slack, the file goes where you send it, through that service.

  • Processed on your device

    Supported conversions run on your computer, using tools installed there.

  • No conversion uploads

    There's no cloud step to change a format. No account, no queue.

  • Open source

    Read exactly what it does. Source on GitHub.

  • One update check a day

    Once a day the app asks mcgyver.ferdiunal.tr whether a new version is out. The request carries the app version, the operating system and its version, the processor type, the app’s language, and a machine ID that is a one-way hash of the system’s own ID. The server also sees the IP address and its country, and keeps them with that ID. No files, file names or what you do with the wheel ever leave the computer. Start the app with MCGYVER_OFFLINE=1 and it never asks.

10 · FAQ

Questions. Answered.

Is McGyver free?

Yes. There's no paid version. You can sponsor it on GitHub if you'd like to support the work.

Is it open source?

Yes. The source is on GitHub.

Do my files get uploaded?

Not for conversion. Supported conversions run on your computer. If you choose to share a file, for example to WhatsApp or Slack, it goes to that service because you sent it there.

Which operating systems are supported?

KDE Plasma 6 on Linux (Wayland), macOS 11 or later, and Windows 10 and 11.

Does it need an internet connection?

Not to convert files. Sharing to online services needs a connection, like it would anywhere else.

Does McGyver send anything?

Once a day it asks mcgyver.ferdiunal.tr whether a new version is out, and tells it the app version, the system, the processor type, the language and a one-way hash of the machine’s ID. The server sees the IP address too. More on this.

Why does macOS show a security warning?

The Mac build isn't notarized by Apple yet. The first time, Control-click McGyver in Applications and choose Open (from macOS 15 on, open it once, then choose Open Anyway in Privacy & Security).

Which file types can I convert?

Pictures, video, audio, PDFs, documents, spreadsheets, slides, archives, subtitles and folders. See the full list.

Does McGyver need FFmpeg?

Only for video and audio. Everything else works without it.

How can I contribute?

Open an issue, send a pull request, or test a build on your machine and report back. Start at the repository.
